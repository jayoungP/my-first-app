# 효모 발효 탐구실 — 구글 시트로 제출받기

학생이 웹 앱에서 실험하고 제출하면, 선생님의 구글 시트 `제출` 탭에 한 사람당 한 줄씩 자동으로 쌓입니다.
선생님은 같은 웹 앱의 **교사용** 탭에서 답안·실험 결과를 보고 채점하며, 채점 결과도 시트에 기록됩니다.

필요한 파일은 이 폴더의 두 개입니다.

- `Code.gs` — 시트에 저장하고 읽는 코드
- `Index.html` — 학생·교사 화면

## 처음 한 번만 하는 설정 (10분 정도)

1. **구글 시트 만들기**: 학교 구글 계정으로 새 스프레드시트를 만들고 이름을 정합니다. (예: `2학년 발효 수행평가`)
2. **Apps Script 열기**: 시트 메뉴에서 **확장 프로그램 → Apps Script**를 누릅니다.
3. **Code.gs 붙여 넣기**: 왼쪽의 `Code.gs`를 열어 원래 내용을 모두 지우고, 이 폴더의 `Code.gs` 내용을 통째로 붙여 넣습니다.
4. **Index.html 만들기**: 왼쪽 **파일 옆 `+` → HTML**을 누르고 이름을 `Index`로 적습니다. (`.html`은 자동으로 붙습니다)
   만들어진 파일의 내용을 모두 지우고, 이 폴더의 `Index.html` 내용을 통째로 붙여 넣습니다.
5. **저장**: 위쪽 디스크 아이콘(💾)을 누릅니다.
6. **배포**: 오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 유형 선택(톱니바퀴) → **웹 앱**
   - 설명: 아무거나 (예: `발효 수행평가`)
   - **다음 사용자 인증 정보로 실행: 나**
   - **액세스 권한이 있는 사용자: ○○학교 내 모든 사용자** (학교 도메인 이름이 보이는 항목)
   - **배포**를 누르고, 권한 요청이 나오면 내 계정을 골라 **허용**합니다.
     ("확인되지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 누릅니다. 내가 만든 스크립트라서 나오는 경고입니다.)
7. **웹 앱 URL 복사**: 배포가 끝나면 나오는 `https://script.google.com/macros/s/.../exec` 주소를 학생들에게 나눠 줍니다.

> 시트에 `제출` 탭은 첫 제출이 들어올 때 자동으로 만들어집니다.

## 수업에서 쓰기

- **학생**: 학교 구글 계정으로 로그인한 상태에서 웹 앱 주소를 엽니다. STEP 1~6을 진행하고 마지막에 **선생님께 제출하기**를 누릅니다.
  - 작성 중인 내용은 그 기기의 브라우저에 자동 저장됩니다.
  - 마감 전에는 고쳐서 다시 제출할 수 있고, 시트의 같은 줄이 새 내용으로 바뀝니다.
  - 다른 기기에서 열어도 이미 제출한 답안을 불러옵니다(같은 학교 계정일 때).
- **선생님**: 같은 웹 앱 주소를 열면 위쪽에 **교사용 · 제출 모아보기** 탭이 보입니다.
  - 학생을 고르면 답안, 설계, 결과표·그래프, 자동 점검(선생님에게만 보임)이 나옵니다.
  - 네 영역(변인 설정·실험 설계·결과 분석·결론 도출)을 평가하면 추천 점수가 표시되고, 최종 점수는 평가 기준 7단계 중에서 고릅니다. **채점 저장**을 누르면 시트에 기록됩니다.
  - **제출 받는 중** 체크를 끄면 마감되어 학생이 더 이상 제출할 수 없습니다.
  - 새로 들어온 제출은 **새로 고침**을 누르면 나타납니다.
  - **구글 시트 열기**로 전체 표를 볼 수 있습니다. 시트의 숨겨진 맨 오른쪽 세 칸(ID, 원본, 채점)은 웹 앱이 쓰는 값이니 고치지 마세요.

## 액세스를 '모든 사용자'로 배포했다면 (선생님 비밀번호)

로그인하지 않고도 열리게 배포하면 웹 앱이 선생님 계정을 알아볼 수 없어서 교사용 탭이 보이지 않습니다.
`Code.gs` 맨 위의 `const TEACHER_KEY = '';` 따옴표 안에 영어·숫자 비밀번호를 적고(예: `'bio2ferm'`) 저장한 뒤 새 버전으로 다시 배포하세요.
그리고 웹 앱 주소 끝에 `?key=비밀번호`를 붙여 엽니다. (예: `https://script.google.com/macros/s/.../exec?key=bio2ferm`)
학생에게는 `?key=` 없는 주소만 알려 주세요.

## 다른 선생님도 채점하게 하려면

Apps Script 화면 왼쪽 **⚙ 프로젝트 설정 → 스크립트 속성 → 스크립트 속성 추가**에서
속성 `TEACHERS`, 값에 선생님 이메일을 쉼표로 이어 적습니다. (예: `park@school.kr, lee@school.kr`)

## 코드를 고친 뒤에는

**배포 → 배포 관리 → (연필 아이콘) → 버전: 새 버전 → 배포**를 눌러야 학생 화면에 반영됩니다. 주소는 그대로입니다.

## 알아 둘 점

- 학생 계정이 학교 도메인이 아니면(개인 Gmail 등) 접속이 막힙니다. 개인 계정까지 받으려면 6단계에서 **Google 계정이 있는 모든 사용자**를 고르세요. 이때는 학생 이메일을 알 수 없어서 **학번+이름**으로 학생을 구분합니다. 같은 학번·이름으로 다시 내면 같은 줄이 바뀝니다.
- 실험 수치는 경향을 보여 주는 교육용 모델로 만든 값이며, 실험할 때마다 조금씩 달라집니다.
